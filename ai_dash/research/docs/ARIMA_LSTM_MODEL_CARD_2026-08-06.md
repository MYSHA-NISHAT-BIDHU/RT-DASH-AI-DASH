# ARIMA + LSTM Thesis Forecasting Model Card — 6 August 2026

This remains the locked thesis-anchor model card. The additive post-lock
robustness model is documented separately in
`ARIMA_LSTM_ADVANCED_MODEL_CARD_2026-08-06.md` and does not replace this model.

## Intended use

Reproduce and validate the predictive-resource component described in the MSc
thesis, then test its use as an advisory input to RT-DASH in software
simulation. This model is not a physical resource estimator.

## Data provenance

Source: `processed_smart_home_dataset_with_resources.csv`.

- 1,164,409 archived source rows;
- 0 unparseable timestamps under the documented mixed-format parser;
- 1 terminal row missing all four resource values; dropped, never imputed;
- 168,923 missing `Activity` values caused by the thesis preprocessor's omitted
  `leisure` mapping; mapped to non-critical `other` only for scheduler-event
  integration;
- CPU, Memory, Storage and Bandwidth are **synthetic annotations generated by
  the thesis preprocessing script**.

Resource values are resampled into non-empty 60-second means. Forecast windows
cannot cross a timestamp discontinuity.

## Models

### Persistence

Predict the next resource vector as the most recently observed resource vector.
It is mandatory because the synthetic resource series is highly persistent.

### ARIMA(5,1,0)

First-difference each resource series, fit an AR(5) with intercept by
conditional least squares on train data, and recursively add the predicted
difference to the last observed level. Models are separate for the four
resources.

### LSTM

- inputs: 4 standardized resource values per time step;
- sequence length: 12;
- hidden units: 16;
- outputs: 4 next-step standardized resources;
- optimizer: Adam, learning rate 0.005;
- batch size: 128;
- maximum epochs: 40;
- validation patience: 6;
- gradient clip: 5;
- seed: 20260806;
- executed epochs: 23; best validation epoch: 17.

The LSTM is implemented directly in NumPy with BPTT. Unit tests cover learning
behavior and compare analytical BPTT gradients with finite-difference
gradients.

### Thesis hybrid

Use ARIMA for CPU and LSTM for Memory, Storage and Bandwidth. Each predicted
resource is mapped to its percentile in the train resource distribution; the
advisory pressure score is `0.4 CPU + 0.2 Memory + 0.2 Storage + 0.2 Bandwidth`.

## Scheduler integration

Validation-only tuning selects pressure threshold 0.809598008 using 972
scheduler simulations. The frozen threshold is then evaluated in 714 test
simulations across three background loads and seven scheduling policies.

Predictive-only RT-DASH mean high-criticality DMR is 0.000000; load-only RT-DASH
is 0.032169 and semantic RT-DASH is also 0.000000. Versus semantic RT-DASH,
predictive-only has a paired +0.372825 ms high-criticality response difference.
Safe recovery prediction exactly matches deterministic recovery-aware RT-DASH
on protected DMR, low linear utility and Critical-Mode fraction.

## Limitations and prohibited use

- resource columns are synthetic, not measured physical resource usage;
- one OpenSHS-derived processed trace and three test dates limit external validity;
- forecast scores are percentile pressure, not calibrated probabilities;
- no physical timing, WCET, energy, certification or universal schedulability claim;
- test results must not be used to redesign this frozen branch without new
  confirmatory data.
