# Journal Experimental Protocol V2

## Evidence scope

All evidence is generated by deterministic, single-core software simulation. The Python simulator is the authoritative experiment engine. The C++17 host simulation is an independent semantic parity check and is not combined with the Python runs as a statistical population.

## Job semantics

- Periodic jobs are released at fixed periods and phases.
- Event jobs are released at explicit timestamps.
- EDF uses absolute deadline order.
- RMS uses period order; isolated event jobs use relative deadline as the documented effective period.
- Static criticality-first EDF orders by criticality, then absolute deadline.
- RT-DASH uses EDF in Normal Mode and criticality-first EDF in Critical Mode.
- Unfinished jobs are dropped at their absolute deadlines to prevent obsolete backlog.
- Declared optional work may be removed only down to each task's service floor.

## Mode semantics

Critical Mode is entered by either:

1. an immediate high-criticality event trigger; or
2. sustained smoothed utilization above the upper threshold.

Normal Mode is restored only after no high-criticality work is pending, smoothed utilization is below the lower threshold, and the configured recovery hold has elapsed.

## Principal controlled study

- 30 matched seeds: 0–29.
- 60,000 ms run duration.
- 10 ms scheduling quantum with work-conserving residual dispatch.
- 9 policies.
- 28 scenario/load cells.
- 7,560 controlled runs.

Scenarios include routine, overload, mild/moderate/severe emergencies, prolonged emergency, threshold chatter, recovery backlog, and optional-service stress.

## Sensitivity study

One factor is varied at a time around the nominal RT-DASH configuration:

- upper utilization threshold;
- hysteresis gap;
- recovery hold;
- observation-window duration;
- smoothing-sample count.

Four scenarios and ten seeds are used, producing 880 runs.

## Scalability study

Task counts: 8, 16, 32, 64, and 128.  
Nominal utilizations: 0.75, 0.95, and 1.15.  
Policies: EDF, static criticality-first EDF, and RT-DASH.  
Seeds: 10.  
Total: 450 runs.

## Trace-mapping robustness

Five contiguous OpenSHS-derived windows are evaluated under three task-mapping profiles:

- relaxed: budget ×0.75, deadline ×1.25;
- nominal: budget ×1.00, deadline ×1.00;
- stressed: budget ×1.25, deadline ×0.85.

Six core policies are evaluated, producing 90 runs.

## Statistics

- paired differences on identical scenario/load/seed cells;
- 10,000-resample bootstrap confidence intervals;
- Wilcoxon signed-rank tests;
- Holm family-wise correction;
- Cohen's dz;
- rank-biserial effect size;
- means, standard deviations, medians, and interquartile ranges.

## Reproducibility

The package includes configurations, source code, tests, raw run-level summaries, representative job-level traces, transition logs, generated figures, an execution manifest, and SHA-256 hashes.
