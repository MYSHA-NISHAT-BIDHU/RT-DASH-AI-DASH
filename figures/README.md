# Figures

Place only a small set of publication-quality figures that help a reviewer understand the project.

Recommended choices:

1. RT-DASH architecture / mode-transition overview
2. Key held-out scheduling comparison
3. AI-DASH prediction-to-scheduler workflow
4. One robustness or forecasting-result figure

Use figures you own or are permitted to redistribute. Avoid uploading publisher-formatted figures if reuse terms are unclear.
