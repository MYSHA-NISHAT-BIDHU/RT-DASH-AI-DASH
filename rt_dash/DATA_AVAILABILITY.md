# Data Availability

The OpenSHS-derived Smart Home Dataset cited by the manuscript is publicly available through Mendeley Data, Version 1:

- P. Lutta, *Smart Home Dataset*, Mendeley Data, Version 1, 2024.
- DOI: <https://doi.org/10.17632/zgsw84b2ff.1>
- License stated by the repository: CC BY 4.0.

For exact computational traceability, File S1 includes the project snapshot used for trace-window selection as `data/raw/smart_home_dataset.csv`. Its SHA-256 digest, dimensions, and field inventory are recorded in `data/SOURCE_DATA_PROVENANCE.md`.

The simulator source, configurations, run-level outputs, statistical tables, representative traces, figures, firmware sources and build artifacts, validation records, manifests, and checksums generated for the study are contained in this same File S1 archive.

No physical-board timing data, measured worst-case execution-time data, energy measurements, or hardware deadline-performance data were generated in this study.
