# RT-DASH Source

Copy the authoritative RT-DASH Python implementation from the validated research project into this directory.

The validated project record identifies the authoritative Python implementation under:

- `research/rt_dash`
- supporting scripts under `research/scripts`

Do not upload legacy/broken scheduler code as if it were the authoritative implementation.

Recommended contents after copying:

- scheduler implementation
- task/job model
- workload generation/loading
- mode controller
- metrics/evaluation logic
- experiment runners
- verification helpers
